# 实施计划

设计已获用户“开始吧”确认。当前环境没有 writing-plans 技能文件，因此在此直接记录可执行步骤。

1. 在现有 SQLite/SQLAlchemy 中新增历史、版本、分类、入库任务表；扫描旧结果并提供浏览器导入。先验证两份独立客户端可读取同一历史，以及去重和删除标记。
2. 新增历史/分类 API，并在生成提交和完成时保存元数据及版本；列表分页，正文按需加载。验证分类不产生外部调用。
3. 改造历史界面及任务缓存：多选、分类目录、未归类筛选、名称/时间排序、三种手动入库、状态和重试。
4. 新增持久化入库工作进程、WebDAV 客户端和 Obsidian 输出规范；对接服务器上实际存在的 Hermes 与 QQ 通道。验证完成回执、文件校验、附件、失败恢复和重复提交。
5. 使用隔离数据库、模拟外部服务进行针对性后端测试，执行前端构建和浏览器交互检查；请求独立代码审查并修复问题。
6. 检查服务器现有部署，备份数据及配置，以可回滚方式部署到现有服务；验证跨浏览器历史和实际入库流程。

代码注释使用中文，UI 使用 Tailwind CSS。仅操作本需求相关目录和配置，不改动无关服务。
